1Reports page

New sidebar item under Insights. Address /reports?analysis=:id. Also opened from "Download report" on Analysis results and Queue simulation.

2States

No plan yet: only the data report. Out of date: no plan or full report until the plan or checks are updated. Levels come from saved results (a selected, current plan; a current Decision), never from pages visited.

3Level stamp

"Calculated only · not checked by simulation" (plan report) or "Checked by simulation · Decision: …" (full report). The same stamp is printed on the PDF cover and the Excel Read me.

4PDF summary

For managers and supervisors. The list shows exactly the sections the file will have; it is generated from the same rules as the file, so the preview and file always match. Parts that need the checks say "after the checks".

5Excel calculations

For technical readers. Formula check recomputes each period with live Excel formulas where Excel can do it reliably and puts NovaQ's value and the difference beside it.

6Data only

Today's dataset report, kept: the uploaded data as NovaQ read it.

FFormula check, verified example

λ 40/h, μ 15/h, 3 counters. The step formulas (a = λ/μ, ρ = a/c, Erlang C waiting probability, Wq = P(wait)/(cμ − λ)) were recomputed in Python exactly as the cells would and match NovaQ's mmc: Wq 9.5701 min, difference 6.7e-15 min. Not yet opened in Excel itself. SEQUENCE() needs Excel 2021 or Microsoft 365; older Excel needs a helper table (open question).
