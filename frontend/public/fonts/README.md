# NovaQ local fonts

Unmodified WOFF2 assets from the official Inter and IBM Plex repositories. The full applicable SIL Open Font License and copyright notices are included in LICENSE-Inter.txt and LICENSE-IBMPlexMono.txt. See sources.json for pinned commits, exact URLs, byte sizes and SHA-256 hashes.

Inter Variable supplies text weights100-900. IBM Plex Mono Latin1 supplies numeric text at weights400/500/600; fallback fonts cover other characters. No runtime external font requests or CSP changes are required.
